# Technology choices

| Area | Choice and license | Reason and alternative considered |
| --- | --- | --- |
| Runtime | CPython 3.12 baseline, PSF license | Windows wheels and SQLite, ctypes, pathlib, logging and unittest.mock in the standard library. A newer Python can be added to the supported matrix when native wheels and packaging pass. |
| Desktop, tray and playback | PySide6 with Qt Widgets, QSystemTrayIcon and QMediaPlayer, LGPLv3/GPLv3 or commercial | Qt handles Windows widgets, DPI, RTL and audio. Essentials covers M0. M4 adds Qt Multimedia. The 6.12 release supports Windows 10 version 1809 or later and Windows 11. Tkinter would need extra tray and playback integration. [Qt for Python](https://doc.qt.io/qtforpython-6.12/) · [Qt for Windows](https://doc.qt.io/qt-6.12/windows.html) |
| Process identity | psutil, BSD-3-Clause | Straightforward process polling and creation timestamps. WMI adds equipment-specific behavior and complexity. [psutil](https://github.com/giampaolo/psutil/blob/master/LICENSE) |
| Windows integration | ctypes in CPython, Windows SDK APIs provided by the OS | Use Win32 foreground, PID and hotkey APIs and per-user startup. A pywin32 dependency adds binaries for calls with small interfaces. |
| Capture | windows-capture 2.0.1, MIT. The wheel imports NumPy and opencv-python. | The verified wheel targets an exact HWND on supported Windows builds starting with Windows 10 version 1903. The app skips capture when the operation is unavailable. DXGI desktop duplication would consume display frames and creates a privacy risk for window-only capture. [Package](https://pypi.org/project/windows-capture/2.0.1/) · [Windows window capture](https://learn.microsoft.com/en-us/windows/win32/api/windows.graphics.capture.interop/nf-windows-graphics-capture-interop-igraphicscaptureiteminterop-createforwindow) |
| Images | Pillow, MIT-CMU | Write WebP with bounded decoding for imports. Native Qt image encoding would couple storage to the UI runtime. [Pillow](https://github.com/python-pillow/Pillow/blob/main/pyproject.toml) |
| Capture wheel dependencies | NumPy, BSD-3-Clause with bundled permissive licenses, and opencv-python, Apache-2.0 with bundled third-party licenses | The WGC wheel exposes frames as arrays and imports both packages. Game Hub copies the native pixels and encodes them through Pillow. Preserve the dependency notices when freezing. [NumPy license](https://github.com/numpy/numpy/blob/main/LICENSE.txt) · [OpenCV wheel licensing](https://github.com/opencv/opencv-python#licensing) |
| Audio recording | sounddevice 0.5.6, MIT, and SoundFile 0.14.0, BSD-3-Clause | The standard x64 PortAudio binary supplies default local input and libsndfile 1.2.2 encodes Ogg Vorbis. CFFI, pycparser and typing-extensions are pinned wheel dependencies. The bundle preserves native and Python notices. Qt recording alone gives less control over supported encodings and device errors. [sounddevice](https://github.com/spatialaudio/python-sounddevice) · [SoundFile](https://github.com/bastibe/python-soundfile) |
| Database | SQLite, public domain, via sqlite3 | Transactions, constraints and simple local upgrades. A server DB needs a service, and JSON files make relational recovery harder. [SQLite](https://sqlite.org/copyright.html) |
| Steam metadata | vdf, MIT | Use an established parser with sanitized local fixtures. A custom parser would add work for escapes and malformed payloads. [vdf](https://github.com/ValvePython/vdf) |
| Translation | Versioned UTF-8 JSON string catalogs and Qt layout direction | Simple catalogs can be checked for key and placeholder parity. Qt Linguist is an alternative if the string set grows. |
| Development | pytest and pytest-qt, MIT, Ruff, MIT | Unit and Qt integration tests plus a fast lint check. unittest and separate lint tools would add configuration. [pytest](https://github.com/pytest-dev/pytest) · [pytest-qt](https://github.com/pytest-dev/pytest-qt) · [Ruff](https://github.com/astral-sh/ruff) |
| Packaging | PyInstaller one-folder, GPL-2.0 with distribution exception and Apache-2.0 components. Inno Setup under its own license, free for non-commercial use | One-folder keeps Qt libraries accessible and simplifies debugging. Inno produces the per-user installer. Verify the selected compiler license on the runner. [PyInstaller](https://pyinstaller.org/en/stable/license.html) · [Inno Setup](https://jrsoftware.org/inno-setup) |
| Source and CI | Git, GPL-2.0, GitHub CLI, MIT, and GitHub Actions hosted service | Private remote, Windows CI on pushes, release packaging on milestone tags. No deploy keys or third-party network dependencies in the packaged app. [Git](https://git-scm.com/about/free-and-open-source) · [GitHub CLI](https://github.com/cli/cli) |

Before shipping each release, inventory the pinned dependency and its bundled DLLs, carry the required notices and source offers, check known advisories, and keep the redistributed libraries replaceable where their license requires it. Check the resulting installer contents on a machine without Python. The project's source remains all rights reserved pending the owner's decision.
