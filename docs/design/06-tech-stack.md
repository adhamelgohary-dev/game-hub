# Technology choices (v1.1)

| Area | Choice and license | Reason and alternative considered |
| --- | --- | --- |
| Runtime | CPython 3.12 baseline, PSF license | Windows wheels and SQLite, ctypes, pathlib, logging, winreg (cleanup only), and unittest.mock in the standard library. |
| Desktop UI & Playback | **PySide6** (`PySide6-Essentials` + `PySide6-Addons`, LGPLv3 dynamically linked) + **custom Fluent QSS stylesheets (Dark & Light)** + `QPropertyAnimation` | Preserves **MIT License** for Game Hub! **`PySide6-Fluent-Widgets` was evaluated and rejected** because its open-source license is **GPLv3 (dual-licensed commercial)**, which would force Game Hub to abandon MIT and violates SignPath Foundation's non-dual-license / license-compatibility simplicity. Custom QSS gives full Windows 11 / Fluent styling, Dark/Light/System themes, smooth transitions, exact Arabic RTL mirroring, and zero extra dependencies. |
| Process watching & Passive protection | `ctypes` (`CreateToolhelp32Snapshot`, `OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)`) + `psutil` (BSD-3-Clause) | Passive basename-only Toolhelp scan detects protected/strict games with **zero `OpenProcess` handles** on protected games. Exact-path verification runs only for non-protected Full-mode games. |
| Capture | `windows-capture` 2.0.1, MIT (uses `numpy` BSD-3-Clause and `opencv-python` Apache-2.0) | Exact-window WGC (`window_hwnd`) with `draw_border=False` on Windows builds >= 20348 (Windows 11+) and graceful fallback to `draw_border=None` on older Windows 10 builds. Active in Full mode only. |
| Images & Cover Art | Pillow, MIT-CMU | Encodes managed WebP screenshots/controls and generates bundled multi-size `.ico` and installer branding assets. Reads local Steam (`appcache/librarycache`) and Epic cover images read-only with stylized vector/gradient placeholders. |
| Audio recording & playback | `sounddevice` 0.5.6 (MIT) + `SoundFile` 0.14.0 (BSD-3-Clause, bundles PortAudio/libsndfile) + QtMultimedia (`QMediaPlayer`) | Bounded 60s Ogg Vorbis voice notes and memory-buffered local playback. |
| Global hotkeys | Win32 `RegisterHotKey` via `ctypes` | No low-level keyboard hook (`SetWindowsHookEx`); dynamically suspended/unregistered during Strict mode. |
| Passive Windows notifications | Windows Toast Notification via WinRT/PowerShell-free Win32/COM or `AppUserModelID` notification adapter | Used only when `protection.external_behavior == "ask_me"`; never draws a topmost window over a running game and never installs a tray icon. |
| Database | SQLite (public domain) via `sqlite3`, Schema v5 | Atomic versioned migrations (`user_version = 5`) with automatic pre-upgrade backup (`gamehub.db-v4.bak`). |
| Steam metadata | `vdf`, MIT | Established local VDF/ACF parser. |
| Packaging & Metadata | PyInstaller one-folder (GPL-2.0 with bootloader distribution exception) + Inno Setup 6 + Windows `VERSIONINFO` resource + UAC `asInvoker` / DPI-aware / Win10-11 compatibility app manifest | One-folder keeps LGPL Qt/FFmpeg libraries cleanly replaceable, deletes legacy `_internal` and v1.0 `Run` registry value on upgrade, embeds version metadata and manifest to reduce AV false positives. |
| Code Signing (Part E) | **SignPath Foundation** free open-source code signing (`signpath/github-action-submit-signing-request`) | Free Authenticode signing on HSM certificate for OSI-approved open-source projects (MIT qualifies cleanly!). Workflow step prepared and disabled via repository variable (`SIGNPATH_ENABLED == 'true'`) until SignPath approves the application. |
| Repo & License | **MIT License** (owner's default), public GitHub repository after Part E secret/PII audit, SemVer GitHub Releases (`vX.Y.Z`) | All runtime dependencies are MIT, BSD, Apache-2.0, PSF, public domain, or dynamically linked LGPLv3/LGPLv2.1 (Qt/FFmpeg), fully compatible with MIT. |
