## 1. Part 1 — Zero-Presence Anti-Cheat Protocol

### 1.1 Architectural Guarantees (Layers 1–7)
1. **Layer 1 — Static & Runtime Never-Interact Guard:**
   - Automated static AST/regex code-scan test (`tests/test_security_invariants.py`) scans every `.py` file under `gamehub/` and packaging manifests and **fails the test suite / build** if any banned symbol appears outside allowed boundaries:
     - `ReadProcessMemory`, `WriteProcessMemory`, `CreateRemoteThread`, `VirtualAllocEx`, `WriteProcessMemory`, `NtReadVirtualMemory`, `NtWriteVirtualMemory`
     - `SetWindowsHookEx`, `SendInput`, `keybd_event`, `mouse_event`
     - `requireAdministrator`, `highestAvailable` (manifest must stay `asInvoker`)
     - `upx=True` in PyInstaller spec
     - Any `OpenProcess` outside `gamehub/core/sessions/processes.py` (where it is restricted exclusively to `PROCESS_QUERY_LIMITED_INFORMATION` on verified non-protected Full-mode targets only).
2. **Layer 2 — Order-Independent, Always-On, Fail-Closed Protection (`ProtectionGuard`):**
   - Runs **before** the main window is shown and **before** `SingleInstance` hands off activation to an existing window (so opening Game Hub a second time from a desktop shortcut while a protected game is running refuses immediately — Case 4).
   - **Startup Self-Check:**
     1. Load `protected_games.json` (schema v2) strictly — missing or corrupt bundled catalog **raises / fails closed** (never silently returns an empty catalog!).
     2. Verify read-only Service Control Manager (`OpenSCManagerW(SC_MANAGER_CONNECT)`) probe succeeds.
     3. Perform an immediate synchronous scan of running process basenames (`CreateToolhelp32Snapshot`) and on-demand anti-cheat services (`EasyAntiCheat_EOS`, `EasyAntiCheat`, `BEService`, `vgc`).
     4. If **any** protected trigger is active (Case 1 / Case 4): show one short modal dialog (*"A protected game or its launcher is running — Game Hub won't run alongside it. Close it first."*, translated in Arabic) and exit with zero library writes and zero game folder access.
     5. If the self-check or catalog fails: show *"Protection could not start — Game Hub will close to keep you safe"* and exit immediately (fail-closed).
   - **Runtime Watchdog (Fail-Closed):**
     - Dedicated `ProtectionGuard` thread polls Toolhelp32 basenames + read-only SCM services every **300 ms** and updates a monotonic heartbeat timestamp.
     - A Qt `QTimer` watchdog runs every **1000 ms** on the main thread: if the guard thread died, recorded an unhandled check error, or its heartbeat is stale (> 2.5 s), Game Hub displays the fail-closed message and exits immediately.
3. **Layer 3 — Exit Before Anti-Cheat Arrives:**
   - `protected_games.json` (schema v2) separates every entry into:
     - `launcher_stage_exes` (e.g., `fortnitebootstrapper.exe`, `fortnitelauncher.exe`, `valorant.exe`, `eaanticheat.gameservicelauncher.exe`, `start_protected_game.exe`)
     - `anti_cheat_exes` (e.g., `easyanticheat_eos.exe`, `easyanticheat.exe`, `beservice.exe`, `vgc.exe`, `fortniteclient-win64-shipping_eac_eos.exe`, `fortniteclient-win64-shipping_be.exe`)
     - `game_exes` (e.g., `fortniteclient-win64-shipping.exe`, `valorant-win64-shipping.exe`, `fc27.exe`, `cs2.exe`, `deadlock.exe`)
   - Top-level catalog fields:
     - `always_strict_launchers`: `{"riot": ["riotclientservices.exe", "riotclientux.exe", "riotclientcrashhandler.exe", "leagueclient.exe", "leagueclientux.exe"]}`
     - `optional_strict_launchers`: `epic` (`epicgameslauncher.exe`), `ea` (`eadesktop.exe`, `ealocalhostsvc.exe`), `battlenet` (`battle.net.exe`), `ubisoft` (`upc.exe`, `ubisoftconnect.exe`), `steam` (`steam.exe`)
     - `anti_cheat_services`: `["EasyAntiCheat_EOS", "EasyAntiCheat", "BEService", "vgc"]` (on-demand services only; excludes boot driver `vgk` and persistent `EAAntiCheatService`, which is covered via `EAAntiCheat.GameServiceLauncher.exe` + game exes).
   - When triggered during runtime (Cases 2 & 3), `ProtectionGuard` fires an immediate emergency exit callback: suspends hotkeys, pauses capture, stops audio, closes window & terminates cleanly in **< 0.5–1.0 s**.
4. **Layer 4 — Launcher & Per-Game Protection Rules:**
   - **Riot Client:** ALWAYS strict (locked ON in Settings; cannot be disabled).
   - **Epic / EA / Battle.net / Ubisoft / Steam:** ALLOWED by default so single-player story games (e.g., *Death Stranding*, *Hue* on Epic) run in Full mode with screenshots, notes, and Last-time card. Optional per-launcher toggle in Settings → Protected games: *"Close Game Hub whenever this launcher is open"* (`protection.strict_launcher.<name>`, default `false`).
   - **Per-game level for protected games:** `strict_exit` (default — refuse to start and exit immediately when active, and auto-exit after Play launch with pending note) vs. `off` (stored as `protection_mode = 'full'` with explicit confirmation warning dialog before disabling). Reset to defaults restores all launcher toggles to OFF (Riot stays locked ON) and game modes to default.
5. **Layer 5 — Official Launcher URI-Only Launch:**
   - Protected games launch exclusively via official URI/launcher handoff (`com.epicgames.launcher://apps/...`, Riot Client detached `--launch-product=<id> --launch-patchline=live`, `steam://rungameid/...`, `origin2://` / EA URI, `uplay://launch/...`, `battlenet://...`, `goggalaxy://openGameView/...`).
   - Game Hub records a `pending_notes` row and exits immediately after handing off to Windows Shell / detached launcher so Game Hub is **never** the parent of a protected game.
6. **Layer 6 — OS & Antivirus Legitimacy:**
   - MIT open-source repo, `VERSIONINFO`, `asInvoker` manifest, `upx=False` PyInstaller one-dir (chosen over Nuitka; see `docs/research/anti-cheat.md` §6 and `DECISIONS.md`), SignPath ready, plus click-only Defender false-positive submission guide (`docs/DEFENDER-SUBMISSION.md`).
7. **Layer 7 & Step C — Test Lab & "Test protection" Button:**
   - Dummy-process lab creates temporary renamed harmless executables (`FortniteLauncher.exe`, `FortniteBootstrapper.exe`, `VALORANT.exe`, `EasyAntiCheat_EOS.exe`, `RiotClientServices.exe`, `EpicGamesLauncher.exe`, etc.) in a temp dir and tests all 4 event orders + fail-closed cases + exit latency.
   - Settings → **Protected games** shows detected protected games on this PC, per-game protection level, per-launcher strict toggles (Riot locked ON), and a **"Test protection"** button that spawns a harmless dummy `FortniteLauncher.exe` child in a sandboxed self-test mode (or runs the live guard pipeline against an isolated subprocess of Game Hub / guard probe) and reports *"Protection OK — Game Hub closed in X ms"*.

## 2. Part 2 — Find All Games (Plugin Detectors + Scan Folders + Clear Warnings)

### 2.1 Root-Cause Fixes Verified on This PC
1. **Epic Games (`gamehub/core/library/epic.py`):**
   - Modern per-user Epic Games Launcher writes installed games to `HKCU\SOFTWARE\Microsoft\Windows\CurrentVersion\Uninstall\EpicGames-*` with `DisplayName`, `InstallLocation`, `EpicAppId` (`namespace:catalogId:appName`), and `DisplayIcon` (no `C:\ProgramData\Epic\EpicGamesLauncher\Data\Manifests\*.item` directory!).
   - `EpicDetector` now scans **both** legacy `Manifests\*.item` **and** `HKCU\...\Uninstall\EpicGames-*` (plus `LauncherInstalled.dat` fallback), deduplicating by `app_name`.
2. **Steam (`gamehub/core/library/steam.py`):**
   - `libraryfolders.vdf` routinely retains offline/unmounted drive letters (e.g., `F:\SteamLibrary`, `X:\SteamLibrary`, `Q:\SteamLibrary` on this PC). `local_path()` rejected unmounted drives (`GetDriveTypeW == DRIVE_NO_ROOT_DIR`), falsely triggering `steam_index_invalid` → `partial`.
   - Fix: distinguish unmounted drive letters (silently skipped as offline drives, matching Steam's own behavior) from truly malformed VDF syntax or unsafe symlinks/UNC paths.

### 2.2 New Read-Only Detector Plugins (`gamehub/core/library/`)
`GameSource` enum expands to: `steam`, `epic`, `riot`, `gog`, `ea`, `ubisoft`, `battlenet`, `itch`, `xbox`, `folder`, `manual`.
- `riot.py` (`RiotDetector`): reads `%PROGRAMDATA%\Riot Games\RiotClientInstalls.json`, `%PROGRAMDATA%\Riot Games\Metadata\*\*.product_settings.yaml`, and `HKCU\...\Uninstall\Riot Game *`. Launches via Riot Client (`RiotClientServices.exe --launch-product=<product> --launch-patchline=<patchline>`). Discovers local `.ico`/cover art.
- `gog.py` (`GogDetector`): reads `%PROGRAMDATA%\GOG.com\Galaxy\storage\galaxy-2.0.db` (read-only SQLite URI `?mode=ro`) + `HKLM\SOFTWARE\WOW6432Node\GOG.com\Games\*`.
- `ea.py` (`EaDetector`): reads `%PROGRAMDATA%\EA Desktop\InstallData\*`, `HKLM\SOFTWARE\EA Games\*`, and `HKLM\...\Uninstall\*` (Electronic Arts publisher with existing `InstallLocation` + game `.exe`).
- `ubisoft.py` (`UbisoftDetector`): reads `HKLM\SOFTWARE\WOW6432Node\Ubisoft\Launcher\Installs\*` (`InstallDir`) + matching `Uninstall\Uplay Install <id>` for display name and `uplay://launch/<id>/0` URI.
- `battlenet.py` (`BattleNetDetector`): reads `HKLM\SOFTWARE\WOW6432Node\Microsoft\Windows\CurrentVersion\Uninstall\*` (Blizzard Entertainment) + `%PROGRAMDATA%\Battle.net\Agent\product.db` / `.build.info`.
- `itch.py` (`ItchDetector`): reads `%APPDATA%\itch\db\butler.db` (read-only SQLite `caves` joined with `games`).
- `xbox.py` (`XboxDetector` improved): adds `MicrosoftGame.config` discovery across `C:\XboxGames`, `D:\XboxGames`, etc. alongside existing StartApps/AppxPackage discovery.

### 2.3 "Scan Folders" (`gamehub/core/library/folder_scanner.py`)
- Persisted folder list in SQLite (`scan_folders` table in Schema v6) + remembered candidate choices (accepted/ignored exes in `scan_folder_choices`).
- Recursively scans user-picked folders (depth-bounded, symlink-safe) for `.exe` files, filtering out non-game helpers: uninstallers (`unins*`, `uninstall*`), crash reporters (`crash*`, `bugsplat*`, `ue4prereq*`, `ueprereq*`), redistributables (`vcredist*`, `dxsetup*`, `directx*`, `dotnet*`, `physx*`, `openal*`), launchers (`launcher*`, `updater*`, `patcher*`), anti-cheat helpers (`easyanticheat*`, `beservice*`, `battleye*`, `vgc*`, `eaanticheat*`).
- Presents a clean Candidate Review dialog where the user ticks games to add and can rename any title inline; choices are remembered so ignored exes don't reappear on future scans.

### 2.4 Plain-Language Partial Scan Banner
- Replace generic/raw partial messages with structured `ScanIssue(source, reason_code)` mapped to plain EN & AR sentences naming the launcher and why (e.g., *"Steam: some game folders could not be read."*), with **Retry** and **Learn more** actions and zero raw internal diagnostic codes.

## 3. Part 3 — Cover Art That Fits
1. **Landscape-First Steam Cover Discovery:**
   - Cards in the Library grid are **wide landscape (`16:9` / `280×158` hero proportion)**.
   - `_find_cover()` in `steam.py` searches **wide assets first** across BOTH flat layout (`<appid>_header.jpg`, `<appid>_library_header.jpg`, `<appid>_library_hero.jpg`) AND nested `librarycache/<appid>/` + hashed subdirs (`header.jpg`, `library_header.jpg`, `library_hero.jpg`), only falling back to vertical `library_capsule.jpg` / `library_600x900.jpg` if no wide image exists.
2. **Center-Crop + Disk Thumbnail Cache (`gamehub/ui/covers.py`):**
   - Always center-crop (`KeepAspectRatioByExpanding` + centered crop rect) — zero stretching.
   - Cache rendered WebP thumbnails on disk under `<data_root>/cache/covers/` keyed by source path + mtime + size + target dimensions for instant startup rendering.
3. **Other Launchers + Local Art + Optional SteamGridDB + Change Cover:**
   - Detect local launcher art (Riot `.ico` / local images, GOG images, Epic/EA/Ubisoft local images or exe icon fallback where appropriate, otherwise clean typographic placeholder with full game name).
   - **Optional SteamGridDB (`gamehub/core/library/steamgriddb.py`):** **OFF by default**, requires user's own API key + explicit consent checkbox in Settings → Library & folders. Strictly the **only** optional network feature in Game Hub; never called unless both enabled and key configured.
   - **"⋯ → Change cover…"** on every game card & Game page lets the user pick a local PNG/JPG/WebP image, copied safely into `<data_root>/media/<game_id>/cover.webp` and saved to `games.cover_path`.

## 6. Part 5 — Rename to "Rewind" (Conflict Check)
Web, GitHub, and Microsoft Store checks performed on 2026-11-24:
- **Plain `"Rewind"` is RISKY:**
  - **Rewind.ai** (now Limitless AI) is a prominent commercial screen + audio memory-recording app — very close in functional domain to Game Hub's screenshot + voice memory recall.
  - **Rewind Software Inc.** (`rewind.com`) holds commercial software brand/trademark presence.
  - **Desktop Rewind** is already published on the Microsoft Store as a Windows rolling visual history app.
- **Safer variants with no direct Windows gaming app conflict found:**
  - **`GameRewind`** (recommended — clear, short, distinctive, zero direct conflict)
  - **`Rewind Games`**
  - **`PlayRewind`**
- Per owner instructions (*"If 'Rewind' is risky, suggest close variants and ask the owner once. Don't block the other parts on this."*), Parts 1–4 and `v1.2.0-rc.1` proceed immediately without blocking, and the owner will be asked once to pick a variant before final rename + `v1.2.0`.
