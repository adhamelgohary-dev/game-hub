## Static Anti-Cheat & Privacy Guardrails (`tests/test_packaging.py`)

Automated AST and source audits enforce:
- Zero network imports (`urllib.request`, `http.client`, `requests`, `httpx`, `aiohttp`, `socket.create_connection`).
- Zero invasive Win32 APIs (`VirtualAllocEx`, `WriteProcessMemory`, `ReadProcessMemory`, `CreateRemoteThread`, `SetWindowsHookEx`, `NtReadVirtualMemory`, `NtWriteVirtualMemory`, `PROCESS_VM_READ`, `PROCESS_VM_WRITE`, `PROCESS_ALL_ACCESS`, `SeDebugPrivilege`).
- Zero `QSystemTrayIcon` references in production code (`gamehub/`).
- Zero `winreg.SetValueEx` calls in production code (`gamehub/`) — only `DeleteValue` for v1.0 legacy cleanup.
