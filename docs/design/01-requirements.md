# Requirements

These requirements trace to the v1 product specification (`STRUCTURE.txt`) and the v1.1 architecture ("Zero background + anti-cheat safe + clean UI + public-ready"). The [implementation plan](08-implementation-plan.md) orders delivery. The [manual checklist](../TESTING.md) records evidence for Windows-specific behaviors.

| ID | Requirement | Acceptance criteria |
| --- | --- | --- |
| R1 | Discover and display the game library | Parse Steam `libraryfolders.vdf` and `appmanifest_*.acf`, Epic `.item` manifests, and supported Xbox/Game Pass folders and packages. Manually add a selected `.exe`. Persist results in SQLite and display cover art (from Steam/Epic local cache or stylized placeholder), name, source, protection badge, last played, and total playtime. Repeat scans without duplicate entries. A missing launcher or malformed individual manifest leaves other entries available. |
| R2 | Zero-background lifecycle and clean exit (v1.1) | Game Hub runs only while its window is open. Remove the system tray icon, "start with Windows", autostart registry creation, and any background service or scheduled task. Upgrading from v1.0 removes the legacy `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\GameHub` entry. Closing the main window releases all threads, timers, capture workers, audio streams, hotkeys, and locks so zero `GameHub` processes remain. |
| R3 | Game-aware lifecycle and Play-through flow (v1.1) | Playing through Game Hub shows the Last-time card, dispatches the launch, minimizes Game Hub with minimal activity while the game runs, shows the optional note prompt on game exit, and then exits completely if opened just for that game (`--play` or exit-after-play toggle) or returns to the library if already open. Session start, end, and duration are recorded cleanly. |
| R4 | Protected-game rules and forgetful-case safeguard (v1.1) | Bundle an updatable JSON catalog of known protected games (`protected_games.json` + optional local override). Default known protected games to **Strict mode** (no periodic WGC screenshots, no in-game hotkeys, no overlays/popups over the game, no microphone during play, no `OpenProcess` handles on protected games; Last-time card before launch and note after exit or on next open if "Exit after launch" is enabled). Default single-player / unprotected games to **Full mode**. Allow per-game override on the Game page. If Game Hub is open and a protected game starts externally, detect it passively by basename only and follow the user setting (`exit_app` default, `strict_mode`, or `ask_me` via a passive Windows notification, never a window over the game). |
| R5 | Preserve recent screenshots (Full mode) | Default to one capture every 30 seconds and a ring of ten captures (configurable). Capture the known foreground Full-mode game window via Windows Graphics Capture only, setting `draw_border=False` on supported Windows builds (with graceful fallback on older builds). Skip minimized, unfocused, unavailable, protected, or black frames. Retain the latest valid captures in order when the session ends. |
| R6 | Save voice and text notes | When enabled, the post-game note prompt offers voice recording (up to 60s), text entry, or dismissal for its originating session. In Full mode, default `Ctrl+Alt+N` starts/stops a short voice note while a tracked game is focused. Deferred pending notes (when Game Hub exited immediately after launching a Strict-mode game) are offered the next time Game Hub opens. Microphone denial leaves text entry usable. |
| R7 | Restore context, pin controls, and review timeline | Show the Last-time card before launch on Play (and on Full-mode external start or `Ctrl+Alt+L` in Full mode). Display prior voice/text notes, last moments carousel, last played, total playtime, and controls card. Pin controls via `Ctrl+Alt+C` (Full mode) or image upload + strategy text on the Game page. Show chronological session timeline with missing-media fallbacks. |
| R8 | Modern Windows 11 / Fluent UI in English and Arabic (v1.1) | Implement Dark and Light themes (plus System follow) with consistent spacing, typography, smooth transitions, local cover art, custom app icon, and branded installer using pure PySide6 QSS (preserving MIT license). Support live English and Arabic switching with full RTL mirroring and LTR isolation for paths, shortcuts, and IDs. |
| R9 | Keep user data local, offline, and anti-cheat safe | Use SQLite (schema v5) and managed media/logs under `%LOCALAPPDATA%\GameHub\` by default. Zero network calls in v1.x. Never inject, hook, read memory of, or open handles with write or debug rights to any game process. Use only public Windows APIs. Log nothing about other processes beyond the game's name and ID. |
| R10 | Public-ready open-source repo, SemVer releases, and code signing prep (v1.1) | Pass full git-history secret/PII audit, add MIT `LICENSE`, `SECURITY.md`, `CONTRIBUTING.md`, updated EN+AR `README.md` with screenshots, third-party notices, EXE version-info and app manifest, and SignPath Foundation signing prep (workflow step disabled until approved). Publish GitHub Releases strictly with Semantic Versioning (`v1.1.0-rc.1`, `v1.1.0`) carrying `GameHub-Setup-vX.Y.Z.exe`, `GameHub-Portable-vX.Y.Z.zip`, and `SHA256SUMS.txt`. |
| R11 | Keep the core available for future modules | Separate the game library, protection catalog, session events, repositories, and Windows adapters from the Memory module UI. |

## Scope exclusions

Video replay buffers, Google Drive backup, local transcription, note search, Launch Doctor, and the Mods & Arabic Translations installer remain future work. Injected overlays, game process hooks/memory access, background daemons/tray icons, networking, accounts, telemetry, and paid APIs remain excluded in v1.x.
