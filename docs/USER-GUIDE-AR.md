# دليل مستخدم Game Hub

يساعدك **Game Hub** على العودة إلى ألعابك الفردية على Windows بعد انقطاع، من خلال تذكيرك بالملاحظات الصوتية والنصية وآخر لقطات الشاشة وبطاقة التحكم قبل استئناف اللعب. يعمل التطبيق بالكامل محليًا دون إنترنت أو حسابات أو تعديل لملفات الألعاب.

## التثبيت والتشغيل

يتطلب التطبيق Windows 10 (الإصدار 1809 أو أحدث، وللقطات الشاشة 1903 أو أحدث) أو Windows 11 بنظام 64 بت، ولا يحتاج إلى تثبيت Python.

1. افتح صفحة الإصدارات الخاصة على GitHub ونزّل **GameHub-Setup.exe**.
2. شغّل المثبّت واتبع الخطوات، ثم افتح **Game Hub** من قائمة ابدأ.
3. للنسخة المحمولة، نزّل **GameHub-Windows-x64.zip** وفك الضغط عن المجلد كاملًا، ثم شغّل **GameHub.exe** (مع إبقاء مجلد `_internal` بجانبه).

للترقية، شغّل الإصدار الأحدث من **GameHub-Setup.exe** فوق التثبيت الحالي مع الاحتفاظ ببياناتك المحلية كما هي. لإزالة التثبيت، أزل **Game Hub** من إعدادات Windows → التطبيقات المثبّتة (مع بقاء بياناتك المحلية محفوظة).

عند إغلاق النافذة الرئيسية يبقى التطبيق نشطًا في شريط المهام (System Tray) لتتبع ألعابك بهدوء. للإغلاق النهائي، انقر بزر الفأرة الأيمن على أيقونة التطبيق في شريط المهام واختر **خروج (Quit)**.

## الميزات الأساسية

- **المكتبة**: يكتشف التطبيق ألعاب Steam وEpic Games Store وألعاب Xbox المحلية المدعومة تلقائيًا. يمكنك أيضًا إضافة أي لعبة يدويًا عبر زر **إضافة لعبة** أو تحديد ملفها التنفيذي عبر **تحديد الملف التنفيذي**.
- **تتبع الجلسات ولقطات آخر اللحظات**: عند تشغيل لعبة معروفة من أي مشغّل، يسجّل التطبيق وقت اللعب تلقائيًا ويلتقط نافذة اللعبة النشطة كل 30 ثانية (تتوقف اللقطات عند تصغير اللعبة أو الانتقال لنافذة أخرى، ويُحتفظ بآخر 10 لقطات افتراضيًا).
- **الملاحظات الصوتية والنصية**:
  - اضغط **Ctrl+Alt+N** أثناء اللعب لبدء تسجيل ملاحظة صوتية (حتى 60 ثانية) واضغطه مرة أخرى للإيقاف والحفظ.
  - عند إغلاق اللعبة، تظهر نافذة اختيارية لتسجيل ملاحظة صوتية أو كتابة ملاحظة نصية.
- **بطاقة آخر مرة وزر لعب (Play)**:
  - عند تشغيل لعبة معروفة، تظهر بطاقة **آخر مرة** مع ملخص الجلسة السابقة وآخر ملاحظة صوتية ونصية وآخر اللقطات وبطاقة التحكم.
  - يمكنك استخدام زر **لعب (Play)** داخل Game Hub لمراجعة بطاقة آخر مرة أولًا ثم الضغط على **تشغيل (Launch)**—وهذا مفيد خصوصًا للألعاب التي تعمل بوضع ملء الشاشة الحصري.
  - اضغط **Ctrl+Alt+L** في أي وقت لإعادة فتح بطاقة آخر مرة.
- **التحكم والخط الزمني**: افتح صفحة أي لعبة لعرض سجل جلساتها الكامل، أو تثبيت صورة لشاشة التحكم بالضغط على **Ctrl+Alt+C** أثناء اللعب، أو رفع صورة محلية وكتابة ملاحظات الاستراتيجية.
- **الإعدادات واللغة العربية**: افتح **الإعدادات** لتغيير اللغة بين العربية (مع اتجاه من اليمين إلى اليسار) والإنجليزية، وتعديل فاصل وعدد اللقطات، والتشغيل التلقائي للصوت، وتفعيل أو تعطيل نافذة السؤال عن ملاحظة عند إغلاق اللعبة، وتخصيص الاختصارات الثلاثة، وتفعيل بدء التشغيل مع Windows، أو فتح ونقل مجلد البيانات المحلي بأمان.

## الخصوصية والبيانات المحلية

- تُحفظ بياناتك محليًا في `%LOCALAPPDATA%\GameHub\` بشكل افتراضي (قاعدة بيانات SQLite واللقطات والملاحظات الصوتية والسجلات).
- لا يتصل التطبيق بالإنترنت، ولا يجمع أي بيانات استخدام، ولا يحقن أي كود داخل الألعاب ولا يقرأ ذاكرتها.
