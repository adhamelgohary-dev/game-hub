## Summary

An independent line-by-line audit of GameRewind's local safety, Translations & Mods engine, storage/migration layer, Inno Setup installer, and Windows CI workflow confirmed strong baseline engineering in several areas:

- **Strong controls verified:**
  - `media.py` pins every ancestor directory via Win32 `CreateFileW` without `FILE_SHARE_DELETE`, opens files with `_OPEN_REPARSE_POINT`, rejects hardlinks (`links != 1`), and enforces bounded reads across `screenshots.py`, `notes.py`, `controls.py`, `covers.py`, and `location.py`.
  - Lazy Pillow imports in `covers.py` and `controls.py` preserve all byte/pixel/format/EXIF sanitization guarantees.
  - `ModsEngine._assert_not_protected()` bypasses `_protected_cache` (`use_cache=False`) before interactive mutations (`import_zip`, `set_enabled`, `choose_conflict_winner`, `remove_item`, `restore_original`), and `require_child=True` prevents DB-tampered deletion of the per-game package root.
  - `packaging/installer.iss` enforces `PrivilegesRequired=lowest` with `PrivilegesRequiredOverridesAllowed=` empty, validates `ValidateInstallDir` in both interactive (`NextButtonClick`) and `/SILENT`/`/VERYSILENT` (`PrepareToInstall`) modes, validates `RunValidatedQuietUninstaller` strictly before touching the filesystem, and only deletes legacy `HKCU\...\Run` keys without ever creating autostart entries.
  - `.github/workflows/windows.yml` pins all 4 third-party actions to 40-char commit SHAs with `persist-credentials: false`, checks `$LASTEXITCODE` after `python -c` in the PE manifest/`VERSIONINFO`/zero-UPX step, enforces the `200 MiB` unpacked / `70 MiB` portable zip size gate and forbidden-binary check, and avoids `${{ github.ref_name }}` shell interpolation.

- **Blocking gaps found (require remediation before rc.3 sign-off):**
  1. **Dotfile-only forbidden extension bypass (`RC3-LOC-01`, HIGH):** `PurePosixPath(".bat").suffix` returns `""` in Python, allowing a mod `.zip` to drop executable scripts/shortcuts named `.bat`, `.cmd`, `.ps1`, `.vbs`, `.js`, `.hta`, `.lnk`, `.reg`, or `.py` into a game folder past `FORBIDDEN_EXTENSIONS`.
  2. **Overlapped/tiny PE bypass (`RC3-LOC-02`, MEDIUM):** `_StreamingPeDetector` discards `e_lfanew < 64`, allowing valid Windows overlapped/tiny PE binaries (`4 <= e_lfanew <= 60`) to bypass PE detection.
  3. **Extraction TOCTOU and missing streaming size/PE caps (`RC3-LOC-03`, MEDIUM):** `extract_verified_package()` re-opens `zip_path` a second time and streams chunks to disk with no `MAX_SINGLE_FILE_BYTES`/`MAX_TOTAL_UNCOMPRESSED_BYTES` caps and without aborting mid-stream on PE detection.
  4. **`is_game_protected()` cache & path-validation flaws (`RC3-LOC-04`, MEDIUM):** `is_game_protected()` calls raw `game.install_dir.stat()` *before* `local_path()` validation (UNC SMB leak / symlink dereference risk), and the mutating `recover_incomplete()` calls `is_game_protected(game)` with the default `use_cache=True`.
  5. **CI `pip install` exit-code masking (`RC3-LOC-05`, LOW):** In both `test` and `release` jobs, `python -m pip uninstall -y opencv-python` runs immediately after `pip install` without checking `$LASTEXITCODE`, resetting `$LASTEXITCODE` to `0` if `pip install` fails.
  6. **Data-folder move drops protection overrides (`RC3-LOC-06`, LOW):** `StoreLocation.move()` omits `protected_games_override.json` when relocating `<data_root>`, silently dropping user-added anti-cheat/protected-game overrides on next launch.

## Surface Verification Checklist

1. **Mods Engine & Manifest (`engine.py`, `manifest.py`)**
   - `is_game_protected()` cache & invalidation: **FAIL** (`RC3-LOC-04` — unvalidated `install_dir.stat()` before `local_path()`, `recover_incomplete()` uses `use_cache=True`).
   - Streaming PE detection: **FAIL** (`RC3-LOC-02` — `4 <= e_lfanew < 64` bypassed; `RC3-LOC-03` — post-write check in `extract_verified_package()`).
   - Forbidden extensions: **FAIL** (`RC3-LOC-01` — dotfile-only names like `.bat`/`.ps1`/`.lnk` bypass `PurePosixPath.suffix`).
   - Zip bombs & `src`-reuse bombs: **PARTIAL / FAIL** (`validate_zip_manifest` blocks both; `extract_verified_package` lacks streaming caps on second open — `RC3-LOC-03`).
   - Case-insensitive collisions, BiDi/control/device-name filtering, `require_child=True`, relative backup/package paths: **PASS**.
   - Reparse/junction safety & rollback: **PASS with INFO** (`RC3-LOC-07`).
2. **Storage & Migration (`location.py`, `covers.py`, `controls.py`, `screenshots.py`, `notes.py`, `media.py`)**
   - Lazy imports (`covers.py`, `controls.py`): **PASS**.
   - Path containment & Win32 reparse/hardlink checks (`media.py`, `screenshots.py`, `notes.py`, `controls.py`, `covers.py`): **PASS**.
   - Migration from `%LOCALAPPDATA%\GameHub` & rollback cleanup (`location.py`): **PASS with LOW finding** (`RC3-LOC-06` — `StoreLocation.move()` omits `protected_games_override.json`).
3. **Installer (`packaging/installer.iss`)**
