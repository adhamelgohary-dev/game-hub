# Red-Team Security Audit — Domain 2: Network, Offline Boundaries & Websites (v1.2 rc.3)

**Scope:** Full `gamehub/` tree at `E:\projects\game hub`, with focused inspection of rc.3 commits `0c61627` and `1417576` (`gamehub/ui/covers.py`, `gamehub/ui/library_view.py`, `gamehub/app.py`, `gamehub/core/library/steamgriddb.py`, `gamehub/core/library/xbox.py`, `gamehub/single_instance.py`, `gamehub/core/library/launcher.py`, `gamehub/core/notifications/windows.py`, plus all detectors, storage modules, and packaging exclusions).

**Verdict:** **FAIL**

---

## Summary

Five of the six Domain 2 controls pass cleanly:

1. **Offline boundary & imports (PASS):** AST enumeration of every Python file under `gamehub/` confirms zero unintended network imports, sockets, HTTP clients, DNS/telemetry/auto-update logic, or external URL fetches outside strictly opt-in `gamehub/core/library/steamgriddb.py`. `packaging/gamerewind.spec` (`0c61627`) additionally strips `QtWebEngine*`, `QtWebSockets`, `QtWebChannel`, `QtHttpServer`, `QtRemoteObjects`, and `opencv-python`.
2. **SteamGridDB opt-in fetcher (PASS):** Strictly OFF by default (`SettingsSnapshot.steamgriddb_enabled = False`, `steamgriddb_api_key = ""`), only invoked via explicit Settings button click (`fetch_missing_covers`), blocks all HTTP redirects via `_NoRedirectHandler`, enforces HTTPS + strict host allowlists (`www.steamgriddb.com` for API; `cdn.steamgriddb.com`, `cdn2.steamgriddb.com` for CDN), never sends `Authorization` to CDN hosts, enforces 6.0 s timeout and 256 KiB / 8 MiB response caps plus image magic & Pillow re-encoding, protects the API key via Windows DPAPI, and never logs it.
3. **Single-instance IPC (PASS):** `gamehub/single_instance.py` uses strictly local `QLocalServer` / `QLocalSocket` (Windows Named Pipe) restricted with `QLocalServer.SocketOption.UserAccessOption`, binds zero TCP/UDP sockets, and reads zero payload bytes on activation.
4. **Launcher URI & executable dispatch (PASS):** `gamehub/core/library/launcher.py` restricts `ShellExecuteW` to 7 strictly `\Z`-anchored game-launcher URI templates (rejecting `http:`, `https:`, `file:`, UNC, and arbitrary schemes/parameters) and spawns local `.exe` / `RiotClientServices.exe` targets only after `local_path()` + non-reparse `lstat()` validation with `subprocess.Popen(..., shell=False)`.
5. **XboxDetector & WindowsNotifier (PASS):** `gamehub/core/library/xbox.py` uses read-only `winreg.KEY_READ` with zero `powershell.exe` / subprocesses and validates all drive/package paths via `local_path()` / `contained_file()`. `gamehub/core/notifications/windows.py` uses native `combase.dll` with zero shell/subprocess spawns.

**Blocking failure — Async cover loading (`gamehub/ui/covers.py`):**

6. **Cover loading follows symlinks and UNC paths (FAIL — `RC3-NET-01`, `RC3-NET-02`):** In `gamehub/ui/covers.py` (refactored for background viewport decoding in `1417576`), `_file_signature()` calls `path.stat()` and `_load_local_qimage()` calls `path.is_file()` + `QImageReader(str(path))` without validating `local_path()` or checking `lstat()` / `FILE_ATTRIBUTE_REPARSE_POINT` / `S_ISLNK`. Because `LibraryRepository._summary()` (`gamehub/core/storage/library.py:118`) and `MemoryRepository` (`gamehub/core/storage/memory.py:216`) reconstruct `cover_path` directly from SQLite without re-validating, any UNC path in `gamehub.db` or any post-discovery symlink/NTFS junction swap inside a game or Steam cache folder is followed on UI render and in the `cover-decode` thread pool — triggering outbound Windows SMB/NTLM network connections (Net-NTLMv2 credential leak and offline-boundary breach) and local symlink traversal. Disk cache operations in `covers.py` (`set_cover_cache_dir`, `_load_cached_disk_image`, `_save_cached_disk_image`) similarly omit `local_path()` and non-reparse checks.

## Final Verdict

**FAIL** — Resolve **`RC3-NET-01`** (HIGH) and **`RC3-NET-02`** (MEDIUM) in `gamehub/ui/covers.py` so that both source cover paths and disk-cache paths enforce `local_path()` + non-reparse (`lstat()` / `media.read_file` / `media.protect_directory`) boundaries and cannot trigger Windows UNC/SMB egress or symlink traversal. Add regression tests proving `CoverLabel`, `load_cover_pixmap`, and `set_cover_cache_dir` reject UNC paths and symlinks/NTFS junctions without touching them.
