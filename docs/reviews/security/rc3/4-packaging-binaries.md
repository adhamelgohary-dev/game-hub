## Executive Summary

All core packaging, binary hygiene, dependency-trimming, manifest, and license-attribution requirements for `v1.2.0-rc.3` **pass verification**:

1. **`ensure_cv2_shim()` (`gamehub/core/capture/windows.py:115-134`):** Safely satisfies `windows_capture==2.0.1`'s unused top-level `import cv2` (`windows_capture/__init__.py:7`) without bundling OpenCV (~126 MiB). Verified against `windows_capture/__init__.py` (only `Frame.save_as_image()` and `DxgiDuplicationFrame.save_as_image()` call `cv2.imwrite`, neither invoked by GameRewind) and `windows_capture.pyd` (zero `cv2`/`opencv` symbols). Non-dunder attributes raise `RuntimeError("OpenCV (cv2.<name>) is not bundled...")`, dunder lookups (`__path__`, `__file__`, `__all__`, `__wrapped__`) cleanly raise `AttributeError`, and `import cv2.submod` fails closed with `ModuleNotFoundError`. Because `ensure_cv2_shim()` registers `sys.modules["cv2"]` prior to `from windows_capture import WindowsCapture`, Python never searches `sys.path`/CWD/`_internal` for a planted `cv2.py`. One Low hardening gap remains if `sys.modules["cv2"]` is pre-populated before `ensure_cv2_shim()` runs (`RC3-PKG-01`).
2. **Packaging Spec, Manifest, Version Info, Dependencies & Licenses:** `packaging/gamerewind.spec` enforces `upx=False` on both `EXE` (L177) and `COLLECT` (L187), sanitizes build-time `PATH` (L11), excludes `psutil`, `cv2`, `PIL.AvifImagePlugin`, and 37 unused `PySide6.*` modules, drops `opengl32sw*` and 32-bit/ASIO PortAudio DLLs, and embeds `GameRewind.manifest` (`asInvoker`, `uiAccess="false"`) and `version_info.txt`. `requirements.txt` pins 11 runtime packages with zero `psutil` and zero `cv2`/`opencv-*` (and CI uninstalls transitive `opencv-python`). All required third-party notices and verbatim license texts (Qt LGPLv3/GPLv3, FFmpeg LGPLv2.1 with zero `--enable-gpl`/`--enable-nonfree` flags, PortAudio MIT, libsndfile 1.2.2 LGPLv2.1 `COPYING`, CPython PSF+Apache-2.0/libffi/bzip2, Pillow, numpy/OpenBLAS, windows-capture, sounddevice, soundfile, vdf, cffi, pycparser, typing-extensions, PyInstaller) are bundled. One Low license-collection gap was found for `soundfile`'s `licensing/license_notes.md` (`RC3-PKG-02`).
3. **Built Artifact (`dist/GameRewind-Portable-v1.2.0-rc.3.zip`):**
   - **File count:** `148` files (`183` entries incl. directories), `85` PE binaries (`.exe`/`.dll`/`.pyd`).
   - **Sizes:** Zip `53,448,385` bytes (`50.97 MiB` < `70 MiB` limit); Unpacked `129,215,049` bytes (`123.23 MiB` < `200 MiB` limit).
   - **Trimmed / forbidden binaries:** `0` `psutil`, `0` `cv2`/`opencv`, `0` `opengl32sw.dll`, `0` `_avif*`, `0` dropped Qt modules (`Qt6Qml`/`Qt6Quick`/`Qt6Web*`/`Qt6Svg`/`Qt6OpenGL`/`Qt6Pdf`/`Qt6Sql`/`Qt6DBus`/`Qt6Xml`/`Qt6Test`) across files, `base_library.zip` (155 entries), and `GameRewind.exe`'s embedded `PYZ.pyz` (559 modules).
   - **PE hygiene (all 85 PEs):** `0` `UPX0`/`UPX!` markers (full-file scan), `85/85` x64 (`0x8664`), `85/85` `DYNAMIC_BASE` (ASLR), `85/85` `NX_COMPAT` (DEP); `GameRewind.exe` additionally sets `HIGH_ENTROPY_VA` and `GUARD_CF` (`DllCharacteristics=0xc160`).
   - **Embedded metadata in `GameRewind/GameRewind.exe`:** Verified `<requestedExecutionLevel level="asInvoker" uiAccess="false"/>` (zero `requireAdministrator`/`highestAvailable`) and UTF-16LE `VERSIONINFO` (`VS_VERSION_INFO`, `CompanyName`, `FileDescription`, `FileVersion=1.2.0.0`, `InternalName`, `LegalCopyright`, `OriginalFilename=GameRewind.exe`, `ProductName=GameRewind`, `ProductVersion=1.2.0`).
   - **Required data:** `GameRewind/_internal/gamehub/core/protection/protected_games.json` present and valid (`schema_version=2`, `updated_at=2026-11-24`, 39 games, 1 always-strict launcher, 5 optional-strict launchers, 3 anti-cheat services, 7 global anti-cheat exes).
4. **AST Security Gate (`tests/test_packaging.py`):** Zero actual policy violations exist in `gamehub/**` today, but rc.3 introduced new patterns (`cv2` shim, `sys.modules` mutation, `QtMultimedia` lazy import, `K32EnumProcesses`) that expose regression-test blind spots (`RC3-PKG-03`, `RC3-PKG-04`).
