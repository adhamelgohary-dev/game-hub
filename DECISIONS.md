# Decisions

| Date | Decision | Reason and alternative |
| --- | --- | --- |
| 2026-11-22 | Complete D before M0 on a fresh workspace. | The setup resume rule points to M0 and the design gate explicitly precedes it. |
| 2026-11-22 | Ship the one-folder bundle and Inno installer from M0 on private milestone releases. | The build instructions make the installer mandatory and specify an early release. The product spec's M8 checks still apply to final clean-machine verification. The executable requires the bundled runtime files. |
| 2026-11-22 | Split private remote creation and the initial push. | This lets us confirm the owner, repository, and visibility before any code is uploaded. |
| 2026-11-22 | Target the exact foreground HWND through Windows Graphics Capture. | It satisfies window-only capture. Desktop duplication would expose pixels outside the game. Validate the pinned wheel in M3. |
| 2026-11-22 | Keep a local SQLite database, file-backed media and a single write coordinator. | SQLite enforces relations and allows atomic DB updates. Staging and reconciliation handle interrupted filesystem changes. JSON alone would make relationships and upgrades fragile. |
| 2026-11-22 | Target CPython 3.12 on Windows x64 first. | The spec permits 3.12 and later. Native wheels and packaged smoke tests gate adding further Python or Windows architectures. |
| 2026-11-22 | Keep repository content in English and reserve Arabic for product localization and the requested Arabic README/user guide. | This keeps technical handoff readable across tools and preserves the product's bilingual experience. |
| 2026-11-22 | Treat the data-folder setting as a managed local relocation. | The setting lists a data folder and the default path is specified. A validated copy can keep the DB and relative media references together. |
| 2026-11-22 | Make Play a preview with an explicit Launch action and deduplicate the corresponding watcher card. | This gives the player time to use the memory card and avoids repeated autoplay. Direct launch after a timer would interrupt reading. |
| 2026-11-22 | Use 1% of one logical core over a 120-second idle sample as the Windows acceptance budget. | This gives the stated near-zero CPU objective a reproducible criterion without hardware-specific percentages. |
| 2026-11-22 | Keep working copies of both inputs and remove the personal owner line from STRUCTURE.txt. | A future contributor can read the complete behavior spec without sharing the owner's identity in repository history. |
| 2026-11-22 | Use PySide6 Essentials 6.12 for the starter release. | M0 uses core, GUI, Widgets and local IPC. The documented Qt floor is Windows 10 version 1809. Add Qt Multimedia with recording and playback in M4. |
| 2026-11-22 | Limit PyInstaller's Windows DLL search path to the selected Python and the operating system. | An unisolated local build pulled incompatible ICU binaries from an unrelated installed app. The isolated bundle started successfully. |
| 2026-11-22 | Use 2.5-second Windows process samples, two confirmed misses, and three consecutive uncertain samples. | This keeps polling inexpensive and separates an actual exit from temporary access loss. Stored duration advances only through reliable observations. |
| 2026-11-22 | Inspect Windows process identity through Toolhelp, limited-information handles, and psutil creation timestamps. | Public image and package APIs meet the process-metadata requirement. The psutil executable accessor can fall back to command-line reads, which the app avoids. |
| 2026-11-22 | Refresh watch targets on committed library changes. | The first full-app idle sample measured 1.0024% of one logical core. Avoiding repeated SQLite target reads reduces idle work and lets the watcher distinguish target changes from process exits. |
| 2026-11-22 | Poll at three seconds and measure the watcher thread separately from total app CPU. | M2's acceptance criterion concerns watcher CPU. The app-level measurement includes native Qt and Windows tray work. Keep the 1%-of-one-core watcher budget and report whole-app use in host CPU units. |
| 2026-11-22 | Use the verified Windows Capture 2.0.1 wheel and compositor QPC freshness checks. | It exposes direct window handles and timestamped frames. Preserve the system capture indication and skip unsupported targets. Use the older Windows cursor default only where explicit cursor settings are unavailable. |
| 2026-11-22 | Open managed screenshots through protected Windows handles and give Qt bounded bytes for one selected image. | The file is checked before decoding, and missing media retains its place in the history. Directory pins allow child file operations while denying a rename of the pinned directory. |
| 2026-11-22 | Bind voice recordings to their session before opening the default Windows input. | Background changes cannot redirect the clip. Use a single bounded stream and Ogg Vorbis encoding, with capture starting only after a shortcut or prompt action. |
| 2026-11-22 | Play local voice notes through a bounded Qt memory buffer and correlate explicit launches for 90 seconds. | The decoder receives only verified audio bytes. A scoped launch attempt prevents preview and watcher presentations from playing the same note twice. |
| 2026-11-23 | Remove the system tray icon, Windows startup registration, and all background operation in v1.1, and clean up v1.0 `Run` entries on upgrade/startup. | Eliminating background processes removes residual anti-cheat exposure, simplifies lifecycle reasoning, and ensures closing the main window exits the process completely. |
| 2026-11-23 | Store known protected games in a bundled JSON catalog (`protected_games.json`) with optional local override (`protected_games_override.json`), and detect protected/strict games via passive `CreateToolhelp32Snapshot` basename matching with zero `OpenProcess` handles. | Data-driven classification updates without code changes and avoids triggering kernel `ObRegisterCallbacks` handle telemetry on protected games. Defaulting external protected-game launches to auto-exit protects forgetful players. |
| 2026-11-23 | Use custom Windows 11 / Fluent QSS styling on pure PySide6 instead of `PySide6-Fluent-Widgets`. | `PySide6-Fluent-Widgets` is dual-licensed GPLv3 / paid commercial, which would force Game Hub away from its owner-selected MIT license and complicate SignPath Foundation eligibility. Pure PySide6 (dynamically linked LGPLv3) + custom QSS keeps Game Hub MIT-licensed with zero new dependencies and full Arabic RTL control. |
| 2026-11-23 | Upgrade SQLite to schema v5 (`games.protection_mode`, `games.exit_after_launch`, `pending_notes`) with automatic `gamehub.db-v4.bak` backup. | Supports per-game Strict/Full overrides and deferred post-launch note prompts when Game Hub exits immediately after launching a strict-mode game, while preserving full backward compatibility with v1.0 data. |
| 2026-11-23 | Enable borderless WGC (`draw_border=False`) on Windows builds >= 20348 with automatic cached fallback to `draw_border=None`. | Removes the yellow Windows capture border on supported Windows 11 builds while preserving reliable capture on older Windows 10 builds where `IsBorderRequired` is unavailable. |
| 2026-11-23 | Adopt Semantic Versioning (`vX.Y.Z`, pre-releases `vX.Y.Z-rc.N`) for GitHub Releases while keeping `m9+` as plain internal git tags, and prepare SignPath Foundation free open-source code signing. | Standard SemVer releases with `GameHub-Setup-vX.Y.Z.exe`, `GameHub-Portable-vX.Y.Z.zip`, and `SHA256SUMS.txt` match public open-source expectations and SignPath Foundation requirements. |
| 2026-11-24 | Enforce Zero-Presence Anti-Cheat Protocol (v1.2): fail-closed startup self-check + 300 ms Toolhelp32 basename & read-only SCM service guard (`EasyAntiCheat_EOS`, `EasyAntiCheat`, `BEService`, `vgc`) + 1 s watchdog; exclude persistent `EAAntiCheatService` (covered via `EAAntiCheat.GameServiceLauncher.exe` + game exes); Riot Client always strict; other launchers allowed by default for story games with optional strict toggle. | Non-admin WMI `Win32_ProcessStartTrace` returned `AccessDenied` on Windows 11, and `__InstanceCreationEvent` polls internally via `WmiPrvSE.exe` at 500 ms. Direct Toolhelp32 averages 11.1 ms with zero handles opened and exits well before EAC/BattlEye/Vanguard bootstraps. Real-PC inspection showed `EAAntiCheatService` stays `Running` when EA FC is closed, so excluding it prevents false lockouts while launcher-stage detection still guarantees zero presence. |
| 2026-11-24 | Support both legacy `ProgramData\Epic\EpicGamesLauncher\Data\Manifests\*.item` and modern per-user `HKCU\...\Uninstall\EpicGames-*` (`EpicAppId`) in `EpicDetector`, and skip unmounted/offline drive letters in Steam `libraryfolders.vdf`. | Real-PC diagnosis proved modern per-user Epic Games Launcher installs store Fortnite, Death Stranding, and Hue under `HKCU\...\Uninstall\EpicGames-*` without legacy `.item` files, and Steam's `libraryfolders.vdf` keeps offline drives (`F:`, `X:`, `Q:`) which caused false `steam_index_invalid` partial warnings. |
| 2026-11-24 | Keep PyInstaller `--onedir` (`upx=False`) + `VERSIONINFO` + `asInvoker` manifest + SignPath code signing + Defender submission guide instead of migrating to Nuitka. | Evidence shows both unsigned PyInstaller and unsigned Nuitka executables trigger Windows SmartScreen/AV heuristics until code-signed; PyInstaller `--onedir` avoids `--onefile` temp extraction and UPX triggers while staying fast (~65 s) and reliable with PySide6 and native Rust/CFFI wheels. |
| 2026-11-24 | Upgrade SQLite to Schema v6 (`scan_folders`, `scan_folder_choices`, `games.custom_cover`, per-launcher strict toggles, optional off-by-default SteamGridDB settings) with automatic `gamehub.db-v5.bak` backup. | Persists user scan folders and candidate decisions, preserves manual/SteamGridDB cover art across refreshes, and keeps SteamGridDB strictly opt-in (off by default, requires user API key + consent) as the sole optional network feature. |
| 2026-11-24 | Flag plain `"Rewind"` as trademark/brand-risky (Rewind.ai / Limitless, Rewind Software Inc., Microsoft Store "Desktop Rewind") and propose `"GameRewind"`, `"Rewind Games"`, and `"PlayRewind"` to the owner without blocking v1.2 implementation. | Prevents trademark confusion with Rewind.ai (which also does screen + audio memory recall) while allowing Parts 1–4 and `v1.2.0-rc.1` to ship cleanly before executing the final rename. |
| 2026-11-24 | Rename product, executable, installer, portable zip, data folder (`%LOCALAPPDATA%\GameRewind` with automatic migration from `%LOCALAPPDATA%\GameHub`), and GitHub repo (`game-rewind`) to `"GameRewind"` while keeping internal Python package `gamehub`. | Owner approved `"GameRewind"`. Keeping internal module imports under `gamehub` avoids high-risk mechanical churn across 60+ modules while renaming 100% of user-facing binaries, folders, shortcuts, UI, docs, and release assets. |
| 2026-11-24 | Give `GameRewind` a dedicated Inno Setup `AppId`, enable `DisableDirPage=no` and `UsePreviousAppDir=no`, validate destination writability, add an optional desktop shortcut task, and silently uninstall legacy `Game Hub` (or a previous `GameRewind` in another directory) during `PrepareToInstall`. | Lets the owner pick any writable folder on fresh installs and upgrades, cleanly removes old `Game Hub` shortcuts/files/uninstall entries without touching `%LOCALAPPDATA%\GameHub`, and avoids duplicate installations when changing folders. |
| 2026-11-24 | Simplify Part 6 (`Translations & Mods`) to a jargon-free On/Off list + `"Restore the original game"` + plain two-button conflict chooser + crash-safe journal + declarative-only manifest validator, upgraded to SQLite Schema v7 (`gamehub.db-v6.bak`). | Owner approved Mods & Arabizations with the requirement to remove profile chips and priority numbers so any player can safely toggle translations/mods and restore original files with one click, while hard-blocking online/protected games and any mutation while a game is running. |
| 2026-11-24 | Remove `psutil` completely (`excludes=['psutil']`) and replace process creation timing with single-handle `kernel32.GetProcessTimes` on `PROCESS_QUERY_LIMITED_INFORMATION` strictly for verified Full-mode single-player targets; replace Xbox `powershell.exe` with read-only `winreg`. | Red-Team audit found `import psutil` calls `AdjustTokenPrivileges("SeDebugPrivilege")` on startup and bundles `_psutil_windows.pyd` (`ReadProcessMemory` import) solely for `create_time()`. Removing `psutil` and PowerShell eliminates unnecessary privileges and AV/anti-cheat heuristics. |
| 2026-11-24 | Exclude idle `vgc` / `vgc.exe` (alongside boot driver `vgk` and `vgtray.exe`) from active blocklists while blocking all Riot Client binaries (`Riot Client.exe`, `RiotClientServices.exe`, etc.) and Valorant/LoL/2XKO executables; arm a 200 ms `os._exit` failsafe and use `QueryUnbiasedInterruptTime`. | Real-PC evidence showed `vgc` often stays `Running` after closing Valorant or permanently when set `Automatic` (Riot VAN 1067/9003 fix), which would brick GameRewind on idle machines. Blocking Riot Client + Riot game launch stages exits in ~110–190 ms while keeping single-player usage smooth. |
| 2026-11-24 | Remove `psutil` completely (`gamehub/`, `tests/`, `requirements.txt`, `gamerewind.spec`) and replace process creation-time lookup with `kernel32.GetProcessTimes` on `PROCESS_QUERY_LIMITED_INFORMATION` (`0x1000`) restricted to verified Full-mode tracked games, plus pause `CaptureScheduler` when zero Full-mode games are active. | Round 1 Red-Team audit (`STATIC-001`..`003`, `PROC-01`..`03`) showed `import psutil` calls `AdjustTokenPrivileges("SeDebugPrivilege")` on startup and bundles `_psutil_windows.pyd` (`ReadProcessMemory`). Native Win32 `GetProcessTimes` eliminates the entire binary surface with zero extra dependencies. |
| 2026-11-24 | Exclude persistent `vgc` service / `vgc.exe` from startup refusal (matching `EAAntiCheatService`), switch `ProtectionGuard` to `QueryUnbiasedInterruptTime` + `150 ms` interval, make catalog overrides strictly additive, and use non-blocking Windows notifications + `os._exit` for emergency shutdowns. | Eliminates Vanguard false-lockouts when `vgc` stays running after closing Valorant, prevents Windows sleep/Modern Standby from tripping the watchdog, guarantees `<250 ms` emergency exit without modal `QMessageBox` hangs, and ensures user overrides can never weaken bundled anti-cheat protection. |
| 2026-11-24 | Replace `XboxDetector`'s PowerShell subprocess inventory with direct read-only Windows Registry (`HKCU\...\AppModel\Repository\Packages`) + `MicrosoftGame.config` scanning, and harden Inno Setup destination/uninstaller validation, SteamGridDB redirects/CDN allowlist, and SHA-pinned CI actions. | Eliminates `powershell.exe` spawns on every library refresh (reducing AV/anti-cheat heuristic noise and shutdown latency), prevents accidental installation over unrelated directories or unvalidated uninstallers, and locks down the sole opt-in network path and CI supply chain. |
| 2026-11-24 | Remove OpenCV (`opencv-python` / `cv2`, ~125.6 MiB unpacked) via an in-memory `cv2` stub registered prior to importing `windows_capture`, exclude `cv2` and unused PySide6/QML/OpenGL/plugin/translation/AVIF binaries in `gamerewind.spec`, and retain `PySide6-Addons` (`QtMultimedia` + FFmpeg) for clean-Windows Ogg Vorbis playback. | `windows_capture` imports `cv2` only for unused `save_as_image()` helpers; GameRewind reads `frame_buffer` and encodes WebP with Pillow. Removing `cv2`, `opengl32sw.dll`, unused QML/Quick/plugins/translations/AVIF cuts unpacked size by >55% while preserving all features, `upx=False`, and license compliance. |
| 2026-11-24 | Make `ProtectionGuard` call `os._exit` directly on the guard thread when `hard_exit_on_emergency=True`, add precomputed O(1) trigger maps, and use `kernel32.K32EnumProcesses` PID-diff fast checks at 80 ms (with immediate `CreateToolhelp32Snapshot` on any new PID + periodic 2 s full audit + 240 ms SCM checks). | Eliminates the 200 ms `QueuedConnection` UI-thread wait that caused 360–663 ms rc.2 exit latency, while cutting idle CPU by ~10× (~5.65% → <0.6% of 1 core) with zero process handles opened and zero new DLLs. |
| 2026-11-24 | Lazy-initialize `VoicePlayer` (`QtMultimedia`), defer non-guard startup wiring and Mods directory scanning past `window.show()`, and move cover thumbnail decoding/cropping/caching onto a bounded background worker pool with viewport-aware loading. | Accelerates cold/warm startup and 100-game library scrolling without changing the fail-closed `ProtectionGuard.self_check()` → `SingleInstance` → TOCTOU `check_once()` security order. |
